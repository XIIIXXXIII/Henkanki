# CS:GO Random Loadout — Рандомное оружие каждый раунд

## ВАЖНО: Ограничение этого билда CS:GO (appid 4465480)

Команда `ent_fire weapon_knife addoutput "classname weapon_knifegg"` **НЕ РАБОТАЕТ** в этом билде легаси CS:GO.
Классический трюк с переименованием ножа сломан.

## Рабочий подход (подтверждён Grok)

Нож через `give weapon_knife_X`:
- Либо сразу встаёт в руки (если слот свободен)
- Либо падает красным на землю → **нажми E чтобы подобрать**

## Как пользоваться

### 1. Установить скрипт:
```bash
mkdir -p ~/.local/bin && cp csgo-rand.sh ~/.local/bin/csgo-rand && chmod +x ~/.local/bin/csgo-rand
```

### 2. Запустить генерацию:
```bash
~/.local/bin/csgo-rand          # 12 раундов, F1, 6996 денег
~/.local/bin/csgo-rand 20 f1 20000  # 20 раундов, F1, 20000 денег
```

### 3. В игре:
1. `map de_dust2` (или любая карта)
2. Жди пока загрузится
3. F1 каждый раунд — получишь оружие + нож падает рядом → нажми E

### 4. Перегенерировать:
Просто запусти скрипт снова — новые рандомные сеты.

## Что происходит при F1:
- `slot3; drop` — выкидывает текущий нож (освобождает слот)
- `give <оружие>` — новое оружие в руки
- `give <нож>` — нож падает красным у твоих ног
- В консоли: `== НОЖ УПАЛ - НАЖМИ E ==`
- Нажми E — нож в руках

## Типы раундов:
| Тип | Вероятность | Что выдаётся |
|-----|-------------|-------------|
| FULL BUY | 28% | Рифл + пистолет + все гранаты + броня + дефуз |
| AWP ROUND | 20% | AWP + пистолет + смоук + флеш + броня + дефуз |
| FORCE BUY | 15% | Рифл + пистолет + хе + флеш + кевлар |
| ANTI-ECO | 12% | SMG + пистолет + флеш + кевлар |
| PISTOL/ECO | 15% | Пистолет + флеш (+смоук/кевлар) |
| BONUS DEAGLE | 10% | Дигл + хе + броня |

## Настройки ботов:
- Уровень: эксперт (3)
- Количество: 10
- Реакция: 0.2 сек
- Арсенал: весь разрешён
- Автобаланс: включён
