# Henkanki Mobile

The mobile application is a local-first Expo client for current Android and iOS. It deliberately supports a compact, verified browser-mobile subset—JSON, YAML and plain text—while the full CLI/Desktop engine handles media, PDF, Office and archive adapters where local tools are available.

Run `npm install` and then `npm run android` or `npm run ios` on a supported development host. Older mobile systems belong to the documented `legacy` support tier and are not represented as build targets here.
