# Henkanki for Haiku

This is an **experimental HaikuPorts recipe**, not a claimed released `.hpkg`. Before it can be submitted, a maintainer must replace `CHECKSUM_SHA256` from a signed Henkanki release tarball, validate the Node.js package availability for the selected Haiku architecture, and run the recipe in HaikuPorts.

The intended first target is **Haiku x86_64**. `x86_gcc2` remains a best-effort source compatibility target; RISC-V, ARM and ARM64 are intentionally not promoted to a release guarantee here.
